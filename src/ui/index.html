⚠️ Peligro: Reiniciar Base de Datos a Cero

Antes de usar esta opción, crea una contraseña exclusiva para proteger el borrado. Debe tener al menos 8 caracteres.

Se guardará una huella protegida en este Mac. Si la olvidas, no podrás borrar la base de datos desde el sistema.

Esta acción elimina todas las operaciones y reinicia la base de datos a cero.

Se borrarán irreversiblemente:
  • Todas las ventas y facturas emitidas
  • Todas las cuentas por cobrar y pagos de clientes
  • Todos los gastos registrados y pagos de nómina
  • Todas las mermas, traslados y cierres de caja
  • Se restablecerá el stock del catálogo a su inventario inicial
  • Se reiniciarán las secuencias de comprobantes NCF a 1
